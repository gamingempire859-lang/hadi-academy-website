# The Hadi Academy Website

A modern, responsive static website for The Hadi Academy, Karachi.

## Customization

Before launch, replace the following placeholders in `index.html`:

- `Street # [add exact street number]` with the correct street number.
- Phone and WhatsApp placeholder text with the academy's actual numbers and links.
- Social links currently pointing to `#contact` with the official Facebook, Instagram, TikTok and YouTube URLs.
- The map placeholder with the correct Google Maps embed or pin link.
- Gallery placeholder cards with real academy photographs when available.

The admission form currently displays a confirmation message locally. Connect it to the academy's preferred email, CRM or WhatsApp workflow before production.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.
